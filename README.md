# orthopaede-wels.at – Website (Entwurf)

Neue Fassung der Homepage von Priv. Doz. Dr. Stefan Hofstätter, Facharzt für Orthopädie, Sport und Therapie, Wels.

Reines HTML/CSS/JS ohne Build-Schritt – einfach `index.html` im Browser öffnen oder den Ordner auf einem beliebigen Webhosting (z. B. GitHub Pages) bereitstellen.

## Struktur

- `index.html` – Start
- `ueber-mich.html` – Über mich (Werdegang, Schwerpunkte) – **neu**, gab es auf der alten Seite nicht
- `ordination.html` – Ordination
- `therapiezentrum.html` – Therapiezentrum (Leistungen als aufklappbare Liste)
- `kontakt.html` – Kontakt, Öffnungszeiten, Anfahrt, Karte
- `impressum.html`, `datenschutz.html` – Rechtstexte (aus der bestehenden Seite übernommen)
- `css/style.css` – gemeinsames Stylesheet
- `js/main.js` – mobiles Menü
- `img/` – Bilder

## Offene Punkte vor Veröffentlichung

- **Impressum**: sollte um UID-Nummer, zuständige Ärztekammer und Berufshaftpflichtversicherung ergänzt werden (§ 5 ECG).
- **Datenschutzerklärung**: an tatsächlich eingesetzte Dienste (Analyse-Tools, Terminbuchung) anpassen.
- Inhalte/Texte gegenlesen und freigeben.
- Hosting/Domain-Umstellung (aktuell läuft orthopaede-wels.at über einen anderen Anbieter) mit dem bisherigen Betreuer abklären.
